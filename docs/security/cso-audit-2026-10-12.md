# designon SIC release review — 2026-10-12

Focused release audit of `753e2d0..d4605d7` and the corrections in this release.
Confidence: 8/10 for the reviewed application boundaries. This is a code and
browser review, not a penetration test or fabrication certification.

## Findings and fixes

- The first 3MF wall mesh was non-manifold at corners and lintels despite
  successful parser loads. A bounded exact union now removes interior faces.
  Every edge is tested for two opposite incidences, including scaled output.
- Openings ignored orientation, and merged exterior walls lost room heights.
  The export preserves both; overlapping apertures carry their combined span.
- Print checks measured the original wall thickness rather than the thickened
  export. A 256 mm verdict formerly enabled a 256.85 mm file; this is blocked.
- Wet-room tiles included windows and could exceed the actual wall height.
  Opening and band intersections are now netted from measured wall faces.
- The compact phone header hid city selection. More actions now includes the
  current city and save state, and keyboard/outside-click dismissal works.
  All eight tools have visible labels and 44px targets. Room-key focus scrolls
  without snap pulling a selected name partly outside the viewport.
- Nonbreaking lockfile update patched `source-map-js`; no new dependency.

## Security evidence and limits

No known-key-pattern matches were found in repository Git history. Pattern
scanning is not an exhaustive credential audit. Frontend production audit and
Worker full dependency audit report zero findings. Full frontend audit retains
seven development-only findings (five high, two moderate), in the existing
Tailwind 3/postcss/glob toolchain. Resolving these requires a separately tested
Tailwind major migration; they are not runtime packages in the public bundle.

The Cloudflare frontend now sends CSP, nosniff, a referrer policy and restricted
camera/microphone/geolocation policies. CSP permits existing inline styles and
only the named geocoding/AI destinations; no inline scripts or remote scripts.
GitHub Pages does not apply Cloudflare `_headers`, so its mirror has different
response-header protection. CI actions remain SHA-pinned; write/OIDC grants
remain confined to deployment. The 54 Worker unit cases are now part of the
publish gate alongside the SQLite concurrency proof. No secret or Worker credential was changed.

Import/share sanitization, collection bounds, image/JSON limits, AI draft review
and the SQLite quota coordinator remain. Quota concurrency proof admitted 5/40
requests for one network, then 7/50 others, holding global cap 12. Both live AI
model variables are empty: a production-origin `/trace` probe returns immediate
503 with manual-underlay guidance. AI stays disabled; local geometry, sun,
city selection and export do not depend on it. Re-enabling paid AI still needs
server-verified identity or an abuse challenge; CORS is not authentication.

# designon security review — 2026-10-05

Scope: frontend imports/shares, anonymous Gemini proxy, request validation,
server quotas, dependencies and deployment privileges. This is a focused code
review with regression tests, not a penetration test or production certification.

## Verified improvements

- The previously deployed hardening bounds JSON streaming (12 MB), uploaded
  image data (8 MB), site dimensions and model geometry. Shared/imported plans
  have collection, ID and coordinate bounds; project files are capped at 2 MB.
- Both AI routes reserve daily quota before upstream requests using one SQLite
  Durable Object: 20 per network and 200 globally by default, with hard config
  ceilings. Unavailable quota refuses upstream calls. Only day-specific IP
  hashes and counters are stored; raw IPs are not stored in this object.
- Gemini keys are carried in request headers, not URL query parameters.
  Upstream response bodies are not logged or forwarded; statuses are logged.
  Requests have timeouts and JSON responses have no-store and nosniff headers.
- Frontend image MIME types are bounded; tracing schema validation and the
  user's draft review gate remain. AI drawings never silently replace a plan.
- This change pins GitHub action commits and limits Pages write/OIDC privileges
  to the deploy job. CI runs lint, worker types, audits, unit/browser checks
  and a real SQLite concurrency proof. Ordinary 3D views require no AI request.

## Evidence

- `npm test`, `npm run lint`, `npm run build`.
- `npm run test:e2e`: desktop/phone theme, share, install and local-render tests.
- `npm run check --prefix workers/concept-render`.
- `npm run test:quota --prefix workers/concept-render`: workerd/SQLite admits
  exactly 5 of 40 concurrent calls for one network, then exactly 7 of 50 calls
  from additional networks, keeping a configured global limit of 12. No API
  credential or paid upstream call is used for this test.
- Worker full `npm audit`: zero reported findings at review time.
- Frontend production-only `npm audit --omit=dev`: zero reported findings.
- Frontend full audit: **5 high findings** in the development-only
  Tailwind → chokidar/micromatch/fast-glob → braces chain. The underlying
  [braces advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) has no
  patched version at review time. These packages process trusted build-time
  globs; they are not shipped as frontend runtime code. `npm audit fix` cannot
  resolve them without a Tailwind major migration. This risk remains open;
  the production audit gate does not represent a clean full audit.

## Remaining limits

- The AI API is anonymous. CORS restricts browser origins but cannot authenticate
  direct clients. Distributed callers can exhaust the global daily allowance.
  Request-count caps do not guarantee a fixed currency spend. Before enabling
  paid billing, add server-verified identity or an abuse challenge; never put
  a supposed shared secret into a public frontend bundle.
- No CSP response header, login/authentication audit, exhaustive secret-history
  scan, infrastructure policy review or external penetration test is claimed.
- Local rendering is a clear-sky concept model. It is not a building-code,
  radiometric, daylight certification or structural engineering assessment.

Independent adversarial review confirmed and corrected the degenerate shadow
camera, missing wall shadow receivers and a roof-visibility occlusion mismatch.

# Release audit — 30 October 2026

The prior runtime (921eca4) failed six hosted browser checks: phone gallery
geometry, section-cut presence in split view, and the saved study's missing year,
each in both browser projects. Production and the mirror still served e2b5d18.

Independent review reproduced three additional faults in the actual trim functions:
a cut kept a sofa whose centre survived but whose footprint crossed the new wall;
removing a nested room deleted a sofa still supported by its surrounding room;
and the cheapest cut was refused as a sliver before considering a viable alternative.
Three new unit regressions failed against the original implementation (35 passed,
3 failed), then passed after the fixes. A browser regression covers bulk repair,
its removal notice, and complete Undo/Redo of the room and furniture together.

Furniture support is now checked against the full measured footprint. A cut only
removes newly unsupported pieces; it does not silently clean up pre-existing
invalid furniture elsewhere. Surviving room support preserves furniture when a
nested room is removed. Viable cuts rank before unusable slivers. Bulk repair
reports removed contained rooms, furniture and openings.

The picture caption again carries the full civil date. Its metadata uses the
existing 12px role; nested launcher/thumbnail padding is removed and the dense
time group has a 32px minimum. Existing picture/viewport budgets remain unchanged.
The split's section cut is a viewing control and stays usable; its test now drives
it. Picture mode no longer allows furniture dragging or the floating room-height
editor; Plan's inspector and the full Spatial editor retain those operations.

The untracked gallery measurement script contained TypeScript non-null assertions
in a JavaScript file and failed lint. They were replaced by explicit missing-model
and missing-gallery errors, preserving the diagnostic.

PR #6 remains the sole open PR, a conflicting draft at fd6a2e8. Rechecked against
main: its bounded opening-placement idea is already incorporated. Wholesale merge
would regress newer mechanics; its DOM translation and climate/pricing assumptions
remain unsuitable. Keep its branch and the recovered branch for provenance; see
RECONCILIATION-2026-10-26.md. No dependency, provider, Worker or share schema change.
